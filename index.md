# Reportes Académicos — IA Generativa

Portafolio de prácticas del curso de **IA Generativa** (IBERO), impartido por el profesor **Huber Girón**.  
Cada práctica documenta experimentos reales con modelos de lenguaje grande (LLM) ejecutados localmente con **Ollama**.

---

## Prácticas

| # | Práctica | Tema |
|---|----------|------|
| 1 | [LLM locales con Ollama](practica1/) | Instalación, ejecución y comparación de 7 modelos LLM |
| 2 | [Benchmark de LLM](practica2/) | Requerimientos técnicos, parámetros y benchmarking con Python |
| 3 | [Chatbot con LLM Local](practica3/) | Chatbot web con FastAPI y Ollama: arquitectura, métricas y extensión Page Assist |
| 4 | [Copilotos especializados con Ollama](practica4/) | Perfiles de copiloto, comparación genérico vs. especializado y prompt injection |
| 5 | [APIs LLM externas vs Ollama](practica5/) | Ollama local vs. OpenRouter: comparación de costo, latencia y calidad |
| 6 | [Evaluación de arquitecturas LLM + MQTT](practica6/) | Agente LLM clasificador con salida JSON y publicación MQTT: métricas de clasificación |
